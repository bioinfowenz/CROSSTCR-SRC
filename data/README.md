# Source datasets

[Download the source-data archive](https://github.com/bioinfowenz/CROSSTCR-SRC/releases/download/v1.0/CROSSTCR-SRC_source_data_v1.0.zip).

The archive contains CROSSTCR v1.4.0 JSON and XLSX files and BATCAVE MHC-I and MHC-II mutational-scan workbooks. Both CROSSTCR formats are retained because their fields, missing values and numerical precision differ; they represent complementary views of the same resource. Original files and source labels are preserved.

[SOURCES.tsv](SOURCES.tsv) records source locations, snapshot dates, file sizes and SHA-256 values. Accompanying notices are included in the archive. The source collections cover broader biological settings than the main human paired-chain HLA-I modeling scope; individual analyses use selected records.

## Original resources

- [CROSSTCR database](https://i.uestc.edu.cn/CROSSTCR/) and [publication](https://doi.org/10.1038/s41698-026-01644-2).
- [BATCAVE database files](https://github.com/meyer-lab-cshl/BATMAN-paper/tree/main/results_batman/tcr_epitope_datasets/mutational_scan_datasets/database).

Please cite the original resources when using their data.

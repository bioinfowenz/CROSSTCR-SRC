# CROSSTCR-SRC

Pretrained Shared, Ranking and Construct fusion-model weights.

Download: https://github.com/bioinfowenz/CROSSTCR-SRC/releases/tag/v1.0

The minimal package contains 15 expert checkpoints, 5 gate checkpoints, the shared frozen Ranking encoder, necessary configuration, README and checksums.

Original research variant: r03fold_18eb90111b0496f1f138 (CROSSTCR_SRC_v1_20261020). This is not the later Construct-refit application version or a full-data retrained model. No training code, detailed data partitions or standalone prediction program is included.

The raw-data archive is being prepared separately.
